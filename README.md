# Region Filler — iOS

Помощник для смены региона Apple ID. Приложение генерирует реалистичные «липовые»
данные (имя, фамилия, адрес, город, штат/иль/область, индекс, телефон) под
4 страны:

- 🇺🇸 США
- 🇮🇳 Индия
- 🇹🇷 Турция
- 🇰🇿 Казахстан

UI повторяет системный экран **«Страна или регион»** из iOS, рядом с каждым
полем — кнопка копирования. Тапнул по полю в настройках Apple ID — вставил.

---

## ⚠️ Важно про автозаполнение и «APK»

1. **«APK» — это формат Android.** На iPhone устанавливаются файлы `.ipa`
   через Xcode / TestFlight / AltStore. Этот проект — нативное iOS-приложение
   на SwiftUI.
2. **Автоматически менять регион Apple ID и заполнять системную форму
   «Страна/регион» из стороннего приложения нельзя.** Это закрытая часть
   iOS (Settings → Apple ID → Media & Purchases → View Account →
   Country/Region). Любое стороннее приложение работает в sandbox и не имеет
   доступа к этим экранам — это запрещено политикой Apple и архитектурой iOS.
   В App Store такое приложение не примут.
3. Поэтому максимум, что может сделать легальное приложение, — это
   подготовить корректные данные и дать удобно скопировать их по одному
   полю или скопом. Что и делает Region Filler.

```
│   └── RegionFormView.swift           # UI как в системной форме iOS

```

### Что гарантирует «реалистичность» данных

- Имена и фамилии — распространённые в каждой из стран.
- Города выбираются из реальных, штат/иль/область — соответствует городу.
- Почтовый индекс — берётся из реально существующих диапазонов выбранного
  города (5 цифр для США, 6 цифр для Индии и Казахстана, 5 цифр для Турции).
- Телефонные номера используют действующие коды:
  - **США**: реальный area code (NPA), формат `+1 NPA NXX-XXXX`.
  - **Индия**: мобильный 10-значный, начинается с 6/7/8/9.
  - **Турция**: мобильный `5XX XXX XX XX` (Turkcell / Vodafone / Türk Telekom).
  - **Казахстан**: мобильный `+7 7XX XXX-XX-XX`.

## Сборка

В репозитории нет готового `.xcodeproj` — он генерируется из `project.yml`
утилитой [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
# Установка XcodeGen (один раз)
brew install xcodegen

# Сгенерировать .xcodeproj
xcodegen generate

# Открыть в Xcode
open RegionFiller.xcodeproj
```

В Xcode:

1. Выбрать схему **RegionFiller** и симулятор iPhone (iOS 16+).
2. Нажать **Run** (`⌘R`).

Для запуска на физическом устройстве: в `project.yml` укажите свой
`DEVELOPMENT_TEAM` или задайте Team в Signing & Capabilities.

---

## Альтернатива без XcodeGen

Если XcodeGen не подходит, можно создать пустой проект iOS App в Xcode
(SwiftUI, iOS 16+) и просто перетащить в него содержимое папки
`RegionFiller/` — все исходники самодостаточны и не требуют никаких
зависимостей.
